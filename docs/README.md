# 3分ねこクリッカー

ブラウザだけで遊べる、3分制限のインクリメンタルゲームです。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「3分チャレンジ開始！」を押します。
3. 左側の猫をクリックして「ねこポイント」を増やします。
4. 右側の「施設」で自動生産を増やします。
5. 条件を満たすと「アップグレード」が解禁されます。
6. 3分終了時の累計獲得ポイントがスコアです。

買い物で所持ポイントを使っても、累計スコアは減りません。

## 主なルール

- 制限時間: 180秒
- 初期クリック: 1ポイント
- 最初の施設「ねこバイト」:
  - 15秒に1回、1体につき自動で1クリック
  - クリック強化の倍率も反映
- ねこバイト20体、40体、70体でクリック強化を順番に解禁
- 通常施設は毎秒自動生産
- 施設価格は購入数に応じて指数的に上昇
- 1個 / 最大10個 / MAX のまとめ買い対応（10個モードは資金不足なら買える個数だけ購入）

## 画像の差し替え

プロジェクト内で表示される画像は、すべて次の1ファイルを参照しています。

`assets/cat.png`

このファイルを同じ名前の別画像へ置き換えるだけで、メイン画像・施設画像・アップグレード画像・結果画面画像が一括で変更されます。

## ファイル

- `index.html` : 画面構造
- `style.css` : 配色、固定レイアウト、ショップ表示
- `script.js` : ゲームルール、施設、アップグレード、タイマー
- `assets/cat.png` : 全画面共通画像
- `handoff.md` : 詳細な引き継ぎ資料

詳細は `handoff.md` を参照してください。


## v3 追加仕様

- 「使えるねこポイント」を累計スコアより大きく表示
- 完走した直近10回だけをブラウザに保存
- その10回のTOP5をランキング表示
- 5位以内へ入ると結果画面でランクイン演出

ランキングはブラウザの `localStorage` を利用するため、同じブラウザでページを開く限り保持されます。

## v18変更メモ（展示会向け調整）
このゲームは展示会のミニゲーム集のひとつとして、1台のPCで毎回ちがう人が交代で遊ぶ前提です。

### ねこバイトが後半に化けることに気づける導線
- ねこバイト発動のバッジを大きくし、「バイト○匹 一斉クリック！ +○○pt / 自動生産の○秒分！」と表示。自動生産の20秒分を超えると黄色く大きく震える「大当たり」表示になる。
- 施設カードに「元取り 約○秒」（次の1個が元を取るまでの秒数）を表示。一番早い施設に「いまおトク！」札が付く。マウス系強化が揃うと、札がねこバイトへ移ることで気づける。
- マウス系アップグレードの説明に「ねこバイトのクリックにも乗る！」を明記。
- ねこNEWSに「一斉クリックが自動生産の○秒分に相当」「マウス系はねこバイトにも効く」「一番元が取れる施設は、まさかのねこバイト」などの状況ニュースを追加。

### まとめ買いに気づける工夫
- 「×1 買う」を4秒以内に5回押すと、「10」「MAX」ボタンが黄色く光って揺れ、横に「← まとめて買えるよ！ 指が助かる」が出る。ねこNEWSでも使い方を流す。一度でも10/MAXを使えば出なくなる（プレイごとにリセット）。
- MAXボタンをふだんから少し黄色くし、まとめ買いボタンを一回り大きくした。

### 結果画面
- 「結果をコピー」を削除。代わりに「撮影OK！ この画面をスマホで撮って自慢しよう」をカメラの絵付きで表示。
- PCでは結果画面を左右2列にして、スクロールなしで1画面に収まるようにした（写真に撮りやすい）。

## v20変更メモ（ねこNEWSの調整）
- アップグレード購入時にニュースを強制的に切り替えるのをやめた。出来事は「次に流す1本」として予約するだけにし、今流れているニュースは最後まで流す。
- 施設を初めて1個買った時も「【開業】ダンボール工場が操業開始。最初の製品は猫が占拠」のような出来事ニュースを予約するようにした（アップグレードと扱いをそろえた）。各施設・各アップグレードに専用の見出しを用意。出来事ニュースはピンクの文字。
- 出来事ばかりにならないよう、予約は最新2件まで・出来事を流した次は必ず普通のニュース・25秒以上前の予約は捨てる。
- ネタニュースを7種類から約30種類に増やし、出現率を約15% → 約45%に上げた。ヒント系が2本続いたら次は必ずネタ。直近5本とは重複しない。
- 施設に関するネタは、その施設を1個以上持っている時だけ流れる（まだ買っていない宇宙センターのネタが流れない）。ねこバイトの匹数や猫を押した回数が入るネタもある。
- まとめ買いの案内ニュースも、割り込みではなく予約に変更。
- アップグレードを買うと、ボタンの位置から「導入！」が浮かび上がる（カードがすぐ消えるので、その代わりの手ごたえ）。
- 連打中に文字がドラッグ選択されて青く反転しないようにした。プレイ中は画面のどこでも右クリックメニューを出さない。
